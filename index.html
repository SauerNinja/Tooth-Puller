Types mirror the original library: Byte (1B), Word (2B, uint16 LE), Long (4B, uint32 LE), Bytes (raw, N bytes → hex), LString (length-prefixed string, Creatures-style). Fields read in order, each consuming from where the last left off.

05 — Structure

Visual byte distribution, entropy, and (for Windows PE files) an internal section table — the closest thing here to an actual x-ray.
256 buckets (byte values 0–255), height = frequency. Text files cluster in the printable-ASCII range (32–126); compressed/encrypted data spreads evenly.
